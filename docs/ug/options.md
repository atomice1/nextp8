# Options Menu

The Options menu allows you to configure global settings for nextp8.

## Accessing Options

From the Browse screen press **X** to open the menu, then select **OPTIONS**.

From a running cart press **P** to open the pause menu, then select **OPTIONS**.

## Settings

### Volume

Adjust the global audio volume.

### Autosave

Enable or disable automatic saving of your carts. When enabled, carts are saved automatically when you stop editing.

## Configuration File

Options are stored in `options.ini` on the SD card. You can also edit this file directly to configure nextp8.
