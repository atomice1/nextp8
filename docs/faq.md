Frequently Asked Questions
==========================

**Q: Is nextp8 a PICO-8 implementation for the Next?**
A: This is a PICO-8 *compatible* core. It is not an official PICO-8 build and is not associated with Lexaloffe.**

**Q: Can I run nextp8 under NextZXOS?**
A: No, nextp8 is a custom core and cannot be run from NextZXOS.

**Q: Does nextp8 use the Z80N?**
A: No, nextp8 is a custom core with a 68010-compatible CPU.

**Q: Will nextp8 work with KS1 (issue 2) and KS2 (issue 4) boards?**
A: No, I'm sorry but these boards do not have enough SRAM and the FPGAs are too small.

**Q: Can you create your own carts from scratch?**
A: Yes! There are built-in editors for code, sprites, maps, SFX and music.

**Q: Can you access Splore?**
A: You can download carts from the BBS by name. There is no Splore browser.

**Q: How compatible is nextp8 with PICO-8?**
A: See the [Compatibility](compatibility.md) page.
